# Specification Driven Development

## Flow

1. Developer writes specification: Specification describes what should happen not how.
2. Agent generated plan based on the specification
3. Agent generate a task list
4. Agent generate code based on task list
5. Developer review

## Scenario

### Brown Field Project

**Implementing new feature**

Developer writes specification for the new feature -> paln -> task list -> code -> review

**Code refactoring**

Developer writes specification for the new feature -> paln -> task list -> code -> review

**Remediating vulnerability**

Developer writes specification for fixing the vulnerability.

### Green Field Project

- Write the use cases
- Generate architecture: Here a we can use a skill which is organization specific. It knows approved technologies and patterns.
